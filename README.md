Calculadora en Python

Este proyecto es una calculadora gráfica desarrollada en Python utilizando la librería Tkinter. Permite realizar operaciones básicas como suma, resta, multiplicación y división, además de incluir funciones como borrar un carácter, borrar todo y deshacer.

Características principales
<ul> <li>Interfaz gráfica creada con Tkinter</li> <li>Botones numéricos del 0 al 9</li> <li>Operadores aritméticos básicos (+, –, ×, ÷)</li> <li>Botón "=" para realizar cálculos</li> <li>Funciones especiales: Borrar uno, Borrar todo, Deshacer</li> <li>Manejo de errores (como división entre cero)</li> <li>Estilos y colores personalizados</li> </ul>

Tecnologías utilizadas
<ul> <li>Python 3.x</li> <li>Tkinter</li> </ul>
